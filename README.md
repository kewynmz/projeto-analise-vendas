# Projeto de Análise de Vendas

## Objetivo
Projeto de Business Intelligence desenvolvido para analisar desempenho comercial utilizando Excel, SQL e Power BI.

---

## Tecnologias utilizadas
- Excel
- SQL
- Power BI

---

## KPIs analisados
- Faturamento Total
- Quantidade Vendida
- Ticket Médio

---

## Insights encontrados
- A categoria Serviços apresentou maior faturamento.
- Maio foi o mês com melhor desempenho.
- A região Norte liderou as vendas.
